# История изменений

## [Unreleased]

### Исправления
- Исправлен расчёт налога для ТС с датой постановки в формате ДД.ММ.ГГГГ (раньше считался полный год)
- Обработка ключей кэша ставок (строки → кортежи)
- Исправлена работа с :memory: SQLite для тестов
- Добавлена проверка пустых словарей в get_rate_for_vehicle
- Исправлены hidden imports в сборке PyInstaller
- Добавлена зависимость `xlrd` для импорта `.xls`
- Синхронизированы версии в установочных скриптах и Inno Setup

### Улучшения
- Поиск теперь также по инвентарному номеру и VIN (включая частичное совпадение)
- Копирование/вставка в полях ввода и таблице ТС: Ctrl+C/V/X/A работает при любой раскладке, правый клик — контекстное меню
- Оптимизирован размер exe-файла (~138 МБ вместо ~400 МБ)
- Добавлены исключения лишних библиотек в сборку (torch, scipy)
- Обновлён README для GitHub
- Убраны битые упоминания отсутствующих файлов и некорректные команды в документации
