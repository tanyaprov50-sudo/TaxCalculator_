# История изменений

## [Unreleased]

### Добавлено
- Выбор отчётного года в интерфейсе (комбобокс «Год») — расчёт, отчёты и возраст ТС теперь зависят от выбранного года
- Хранение данных в `%APPDATA%\КалькуляторТН` — работает при установке в Program Files; старые файлы переносятся автоматически
- Автоматическое резервное копирование БД при запуске (1 копия в день, ротация 5) + кнопка «💾 Бэкап БД»
- Экспорт всех данных (базы, организации, ставки, бэкапы) в ZIP-архив одной кнопкой «📦 Экспорт данных (ZIP)»
- Цветовая подсветка статуса: зелёный — ТС поставлено на учёт в выбранном году, красный — списано
- Дедупликация при импорте Excel: существующие ТС (по инв. №, VIN, гос. №) обновляются вместо создания дублей
- Белый список колонок в UPDATE базы (защита от инъекции через имена полей)

### Исправления
- Ставки и налог больше не показываются как 0 при запуске — таблица обновляется после асинхронной загрузки ставок
- Исправлен расчёт налога для ТС с датой постановки в формате ДД.ММ.ГГГГ (раньше считался полный год)
- Убрана побочная запись налога в `tax_history` при перерисовке таблицы (поиск, смена региона) — сохраняются только явные расчёты
- Обработка ключей кэша ставок (строки → кортежи)
- Исправлена работа с :memory: SQLite для тестов
- Добавлена проверка пустых словарей в get_rate_for_vehicle
- Исправлены hidden imports в сборке PyInstaller
- Добавлена зависимость `xlrd` для импорта `.xls`
- Синхронизированы версии в установочных скриптах и Inno Setup

### Улучшения
- Поиск теперь также по инвентарному номеру и VIN (включая частичное совпадение)
- Копирование/вставка в полях ввода и таблице ТС: Ctrl+C/V/X/A работает при любой раскладке, правый клик — контекстное меню
- Легенда подсветки использует те же цвета, что и строки таблицы
- Оптимизирован размер exe-файла (~138 МБ вместо ~400 МБ)
- Добавлены исключения лишних библиотек в сборку (torch, scipy)
- Обновлён README для GitHub
- Убраны битые упоминания отсутствующих файлов и некорректные команды в документации
