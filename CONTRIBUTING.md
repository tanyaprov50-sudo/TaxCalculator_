# 🤝 Вклад в проект

Спасибо за интерес к проекту! Вот как можно помочь:

## 🐛 Нашли ошибку?

1. Проверьте что ошибка ещё не описана в [Issues](../../issues)
2. Создайте новый Issue с описанием:
   - Версия приложения
   - Шаги для воспроизведения
   - Ожидаемое поведение
   - Скриншот (если есть)

## 💡 Предложение новой функции

1. Создайте Issue с меткой `enhancement`
2. Опишите что хотите и зачем
3. Обсудим реализацию

## 🔧 Хотите написать код?

### 1. Форкните репозиторий
```bash
git fork https://github.com/your-username/tax-calculator
```

### 2. Создайте ветку
```bash
git checkout -b feature/название-фичи
# или
git checkout -b fix/название-бага
```

### 3. Внесите изменения
- Следуйте стилю кода проекта
- Добавляйте комментарии для сложной логики
- Пишите на русском (код и комментарии)

### 4. Проверьте работу
```bash
# Установите зависимости
pip install -r requirements.txt

# Запустите приложение
python tax_app.py

# Проверьте синтаксис
python -m py_compile tax_app.py
```

### 5. Сделайте коммит
```bash
git add .
git commit -m "fix: исправлен расчёт ставки для грузовых"
```

**Формат коммитов:**
- `fix:` — исправление ошибки
- `feat:` — новая функция
- `docs:` — документация
- `refactor:` — рефакторинг без изменений логики
- `chore:` — технические изменения

### 6. Отправьте Pull Request
- Опишите что изменено
- Укажите связанный Issue (если есть)
- Дождитесь ревью

## 📋 Правила кода

1. **Кодировка:** UTF-8
2. **Язык:** русский (интерфейс, комментарии, переменные)
3. **Стиль:** PEP 8, но без фанатизма
4. **Макс. длина строки:** 120 символов
5. **Без глобальных переменных** (кроме констант)
6. **Обработка ошибок:** try/except с понятными сообщениями

## ️ Тестирование

Перед PR убедитесь что:
- ✅ Приложение запускается без ошибок
- ✅ Расчёт налога работает корректно
- ✅ Импорт/экспорт Excel работает
- ✅ Нет синтаксических ошибок
- ✅ Сборка в exe проходит успешно

## 📝 Чек-лист перед коммитом

- [ ] Код работает
- [ ] Нет отладочных print()
- [ ] Нет временных файлов
- [ ] README обновлён (если нужно)
- [ ] Коммит описывает одно изменение
- [ ] Сообщение коммита по формату
