# 🚗 Калькулятор Транспортного Налога

![Python](https://img.shields.io/badge/Python-3.12-blue.svg)
![Windows](https://img.shields.io/badge/Platform-Windows-0078D6.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)
![PyInstaller](https://img.shields.io/badge/Build-PyInstaller-orange.svg)

Приложение для расчёта транспортного налога физических и юридических лиц с поддержкой нескольких организаций и автоматическим учётом возраста ТС.

## ⚡ Быстрый старт

### Вариант 1: Скачать готовое приложение
1. Перейдите в [Releases](../../releases)
2. Скачайте `tax_app.exe`
3. Запустите — **Python не нужен!**

### Вариант 2: Собрать из исходников
```bash
# Перейти в папку проекта
cd TaxCalculator

# Установить зависимости
pip install -r requirements.txt

# Собрать exe
python -m PyInstaller --clean tax_app.spec

# Запустить
dist\tax_app.exe
```

## 🎯 Возможности

| Функция | Описание |
|---------|----------|
|  **Расчёт налога** | Формула: `Мощность × Ставка × (Месяцы / 12)` |
| 🏢 **Несколько организаций** | Отдельные БД для каждой организации |
| 📅 **Учёт возраста ТС** | Ставки зависят от года выпуска |
| 🌍 **Регионы РФ** | Пермский край, Москва, СПб, Свердловская обл., Краснодарский край |
| 📁 **Excel импорт/экспорт** | Поддержка `.xlsx` и `.xls` |
| 🔍 **Поиск и фильтрация** | По гос. номеру, марке, типу ТС |
| 📊 **Отчёты** | По годам, по типам ТС, журнал изменений |
| ✏️ **Редактирование ставок** | Ручная настройка налоговых ставок |
| 🖥️ **Полноэкранный режим** | Окно разворачивается на весь экран автоматически |

## Технологии

- **Python 3.12** — язык программирования

## Сборка

### Автоматическая (GitHub Actions)
При создании тега `v*` автоматически собирается exe и создаётся релиз.

### Ручная
```bash
# Установить зависимости
pip install -r requirements.txt

# Собрать
python -m PyInstaller --clean tax_app.spec

# Готовый файл: dist/tax_app.exe
```

## Формула расчёта

```
Налог = Мощность (л.с.) × Ставка (руб/л.с.) × (Месяцы владения / 12)
```

**Ставка зависит от:**
1. Типа ТС (легковые, грузовые, автобусы, мотоциклы, спецтехника)
2. Мощности двигателя (л.с.)
3. Возраста ТС (для легковых автомобилей)
4. Региона регистрации
